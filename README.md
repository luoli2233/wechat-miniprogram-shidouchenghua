# 微信小程序 · 拾豆成画

把喜欢，拼起来。从照片、素材或自由绘画开始，生成自己的拼豆图纸。

拾豆成画是一款微信原生拼豆创作工具，支持照片转图纸、画布自由创作、图层管理、逐格编辑、材料统计和制作进度记录。基础创作无需登录，作品主要保存在本机。

**当前版本：0.1.0 开发预览版。** 自动化检查已通过，内容安全云权限、真机完整验收和平台审核仍需完成。

本仓库是公开的脱敏源码副本。`project.config.json` 使用微信游客 AppID，`miniprogram/cloud-config.js` 使用示例云环境名；文档中的正式 AppID、云环境和旧测试号也已隐藏。要使用登录及内容安全云函数，请先填入你自己的 AppID、云环境并完成部署和权限配置。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 照片转图纸 | JPEG/PNG 导入、裁剪、旋转、镜像、透明区域处理与颜色匹配 |
| 自由创作 | 图片、文字、形状、画笔与擦除，保存创作草稿并生成拼豆图纸 |
| 图层管理 | 素材选择、置顶、上移、下移、指定层级、隐藏、锁定及删除 |
| 图纸编辑 | 单格填色、擦除、吸管、50 步撤销重做、拖动及双指缩放 |
| 品牌参考色板 | Artkal S / MARD 参考 RGB 数据、生成前色差提示 |
| 制作辅助 | 制作进度、逐色用量、采购余量、库存及拼板占位估算 |
| 保存与分享 | 本地作品、总览和分区 PNG、材料清单、微信好友分享入口 |
| 我的 | 微信身份登录、本地自定义名称、工作台设置 |

自动生成时可选 8/12/16/24 色策略；生成后的手动编辑可使用所选色板的全部颜色。品牌参考色表尚未完成实物核验，屏幕、打印与实际豆子可能存在色差。

## 快速开始

### 微信原生小程序

1. 下载并解压项目，或克隆本仓库。
2. 在微信开发者工具中导入仓库根目录，即包含 `project.config.json` 的目录。
3. 使用有项目开发权限的账号；独立运行请配置自己的 AppID 与云环境。
4. 建议使用基础库 3.6.5 或以上。原生端无 npm 运行时依赖，无需执行“构建 npm”。
5. 编译后从首页示例开始体验。登录和内容安全依赖云函数，需要单独部署与配置权限。

云端配置见 [身份登录说明](docs/微信登录_实现说明.md) 和 [云接入说明](docs/微信云备份_部署说明.md)。仓库中的 AppID 和云环境标识不授予对应账号的访问权限。

### 本地检查

准备 Node.js 22.13+ 和加入 PATH 的 Python 3，在根目录执行：

```sh
npm run verify
```

包含核心测试、工程检查及 WXML 结构检查。自动化检查不代替微信编译与真机验收。

### 浏览器预览（可选）

```sh
cd browser-preview
npm ci
npm run dev
```

打开 http://localhost:3000/ 。浏览器端与微信端的本地数据不互通，功能也不完全相同。浏览器遗留的社区草稿和 AI 适配代码不代表原生小程序提供相应服务。

浏览器检查命令：

```sh
npm run lint:app
npm run build
```

## 项目结构

```text
miniprogram/       微信原生小程序：页面、核心算法、存储与主题
cloudfunctions/    微信身份、内容安全等云函数
browser-preview/   可选浏览器预览
tests/             核心算法与交互规则测试
scripts/           工程检查、资源同步和打包脚本
tools/             可选截图与宣发工具
docs/              需求实现、设计、色表来源和验收资料
```

原生页面包括创作、裁剪、编辑、导出、作品、帮助、素材、分享、制作、工作台和我的，共 11 个页面。

## 数据与当前限制

- 作品、素材和草稿主要保存在设备本地。清理应用数据或卸载可能导致丢失，请主动导出备份。云备份默认关闭。
- 内容安全功能需要正确的微信接口权限及真实检测验收；目前仍有发布阻断项，详见验收文档。
- 原生端不包含公开社区、AI 重绘、会员付费或自动发送消息。
- 品牌参考色号和拼板规格尚未完成实物验证；演示色板不能作为采购依据。
- 相册权限、隐私授权、EXIF 图片方向、不同机型手势与性能需要继续真机测试。
