# 微信小程序 · 拾豆成画

把喜欢，拼起来。从照片、素材或自由绘画开始，生成自己的拼豆图纸。

拾豆成画是微信原生拼豆创作小程序，支持照片转图纸、自由创作、图层管理、逐格编辑、材料统计和制作进度记录。基础创作无需登录，作品主要保存在本机。

## 主要功能

- 照片转图纸：导入、裁剪、旋转、镜像、透明区域处理及品牌参考色板匹配。
- 自由创作：图片、文字、形状、画笔、擦除、草稿和素材图层管理。
- 图纸编辑与制作：逐格填色、吸管、撤销重做、双指缩放、用量统计和进度记录。
- 作品保存与分享：本地作品、PNG 图纸、材料清单和微信好友分享入口。

自动生成可选 8/12/16/24 色策略；手动编辑可使用所选色板全部颜色。屏幕、打印与实物拼豆可能存在色差；品牌参考色表尚未完成实物核验。

## 运行与检查

1. 下载并解压上方源码 ZIP，在微信开发者工具中导入其根目录。
2. 使用自己的 AppID 和云环境配置登录、内容安全等云端功能；基础创作可先体验。建议基础库 3.6.5 或以上。
3. 本地安装 Node.js 22.13+ 和 Python 3 后，运行 `npm run verify`。目前通过 106 项测试及 JS、路由、WXML 检查。
4. 可选浏览器预览位于 `browser-preview/`，运行 `npm ci`、`npm run dev`。浏览器预览与微信端功能及本地数据不完全相同。
